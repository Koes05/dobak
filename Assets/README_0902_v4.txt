도박예방게임 Scenario V3 누적 핫픽스 0902 v4

적용 방법
1. Unity를 종료합니다.
2. 현재 프로젝트를 백업합니다.
3. 이 ZIP의 Assets 폴더를 프로젝트 최상위 Assets 폴더에 덮어씁니다.
4. Unity를 다시 열고 Import/Compile이 끝날 때까지 기다립니다.
5. Console의 빨간 오류부터 확인한 뒤 Play 테스트합니다.

v4 핵심 수정

[메시지 확인 전 독백 방지]
- 메시지가 알림으로 도착한 것만으로 후속 독백/연출이 실행되지 않게 수정.
- 후속 대사/독백이 있는 메시지는 실제 해당 채팅방을 열었을 때 읽은 것으로 처리.
- 예: 민재의 첫 알림 -> 민재 채팅방을 실제로 연 뒤에야 주인공 독백과 다음 민재 메시지 진행.
- 단독 안내 메시지(결석 안내, 엄마 용돈 등)는 알림으로 남기되 전체 시나리오를 불필요하게 정지시키지 않음.

[메시지 입력중 연출]
- 플레이어가 메시지를 보낸 뒤 상대 답장이 즉시 튀어나오지 않음.
- 상대 말풍선 위치에 '입력중...'을 약 0.8~1.8초 표시한 뒤 같은 말풍선이 실제 답장 텍스트로 변경됨.
- 연속 메시지 사이에도 읽을 수 있는 텀을 둠.
- 메시지 앱/채팅방을 닫은 경우에도 답장은 알림으로 정상 도착.

[메시지 장면 전환]
- 채팅 중 외부 VN/엔딩/다른 장면으로 이동해야 할 경우, 플레이어가 채팅을 닫기 전에는 넘어가지 않음.
- 같은 인물과 이어지는 메시지 답장은 채팅방 안에서 그대로 진행.
- 주인공이 보낸 메시지는 VN의 '지나간 대화' 기록에 추가하지 않음.
- 메시지 발신은 기존 v3 규칙대로 해당 채팅방의 '메시지 보낸다.'를 눌러야 실제 전송.

[독백 괄호]
- 문장마다 괄호를 따로 붙이는 방식 제거.
- 실제 VN 한 페이지에 표시되는 독백 전체를 괄호 한 쌍으로 표시.
- 긴 독백이 다음 페이지로 넘어가면 다음 페이지에 새 괄호 한 쌍 적용.

[메시지 앱 UI]
- 씬에 남아 있던 예전 '채팅' 텍스트가 좌측 영역 밖으로 튀어나오지 않도록 숨김.
- 사용하지 않는 Stranger / Scammer 연락처 슬롯을 강제로 숨김.
- 메시지 내역은 날짜가 바뀌어도 유지.

[공부 앱 UI]
- 선택지 실제 텍스트 TMP와 번호 TMP를 명확히 분리해 선택지 문장이 번호 원 안으로 들어가는 문제 방지.
- 예전 외부 1/2/3/4 숫자 라벨이 남아 있으면 숨김.
- 선택지 문장 시작 여백 확대.
- 강제 글자수 줄바꿈 없이 TMP 자연 줄바꿈 사용.
- 긴 선택지는 필요한 높이만큼 버튼 높이를 늘리고 아래 선택지를 자동으로 내려 배치.
- 문제 문장 가용 폭을 늘리고 최대 폰트 크기를 낮춰 어색한 단어 중간 줄바꿈을 완화.

[대화 기록 UI]
- History Viewport 영역과 텍스트 폭을 다시 고정.
- RectMask2D 안에서만 표시되게 하고 가로로 영역을 뚫고 나가지 않도록 수정.
- 제목 '지나간 대화' 위치도 상단 패널 안으로 고정.

[시나리오 문맥]
- 민재 알림을 보기 전 '새 메시지가 왔다'며 독백하던 표현을 실제 메시지를 읽은 뒤의 생각으로 변경.
- 첫 도박 후 과제를 이미 끝낸 경우에도 '공부 앱을 먼저 볼지...'라고 단정하던 대사를 중립적인 남은 일정 확인 대사로 변경하고 공부 빨간점 강제 재활성화 제거.
- 3일차에 도박을 한 번도 하지 않은 경로에서는 '나는 저 사례와 다르다', '선을 그어야 한다'처럼 자기 도박 문제를 걱정하는 독백이 나오지 않음.
- 비도박 3일차 저녁은 사례를 발표자료 관점에서 정리하는 별도 장면으로 분기.

[기존 v3 수정 유지]
- 공부 완료 후 공부 앱 자동 종료 / 빨간점 제거
- 앱 오픈 스플래시 완료 후 실제 앱 표시
- 민재 채팅방을 실제 확인한 뒤 도박 앱 해금
- 도박 앱 해금 이후 빨간점 지속
- 늦은 등교에서도 학교 필수 장면 실행
- 결석 시 진행 필수 정보 메시지 전달
- DAY3 민재 대화만으로 날짜 자동 진행하던 문제 제거
- 점장 상담 동기 보강
- DAY6 엄마 용돈 이벤트
- 18:00~20:59 저녁 방 배경
- 회복 엔딩 현재 debt=0이면 무채무 경로 판정

우선 확인할 테스트
A. 민재 첫 알림만 봤을 때 독백이 뜨지 않는지
B. 민재 채팅방을 열면 그때 독백/후속 메시지가 진행되는지
C. 서연에게 '메시지 보낸다.' -> '입력중...' -> 실제 답장 순서인지
D. 채팅 마지막 메시지 뒤 채팅을 닫기 전 외부 장면으로 넘어가지 않는지
E. VN 독백이 한 페이지당 괄호 한 쌍인지
F. 공부 앱 1333/1336/1338 선택지 글자가 파란 번호 영역과 겹치지 않는지
G. 긴 선택지와 긴 문제 문장이 자연스럽게 줄바꿈되는지
H. 지나간 대화가 패널 밖으로 튀어나오지 않는지
I. Stranger / Scammer가 연락처 목록에 나타나지 않는지
J. 도박 0회 DAY3 저녁에 자기 도박 문제를 걱정하는 독백이 나오지 않는지
