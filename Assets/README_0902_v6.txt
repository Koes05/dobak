도박예방게임 0902 v6 누적 핫픽스

적용: Unity를 종료한 뒤 이 ZIP의 Assets 폴더를 프로젝트 최상위에 덮어쓰기.

이번 핵심 수정
- 서준 상환 독백은 도박 배경이 아니라 열린 메시지 화면 위 오버레이로 표시
- 메시지 읽은 뒤 빨간 점이 한 번 더 눌러야 사라지던 상태 분리/동기화
- 같은 시나리오 메시지 line_id 중복 전달 방지
- 필요한 답장 상대는 연락처 최상단, 그다음 최근 송수신 순
- Stranger/Scammer 슬롯은 삭제/재활용하지 않고 생성 즉시 해당 슬롯만 숨김
- 공부 선택지: 우측 정렬, 버튼 오른쪽 이동, 가로/세로 확대, 긴 문장 여유 확보
- 첫 도박 뒤 [한다]/[안 한다] 선택 추가
- 할 일 때문에 도박이 잠긴 경우 무반응 대신 지도/공부 등 해야 할 앱을 안내
- 돈을 빌린 뒤 또 잃어도 다시 차용 선택지 진입 가능
- 엄마/서준/민재 송금 시점에 실제 통장 +50,000 / 채무 +50,000 반영
- 민재 제안까지 거절한 경우에만 최종 '돈을 더 빌리지 않고 멈춘다' 독백
- DAY10 서준 상환: 지금 가진 돈부터 갚기 / 미루기 선택 추가
- 은행 거래내역 최신 거래가 항상 맨 위
- 지나간 대화는 연한 Viewport 내부에서만 마스킹/스크롤
- 18:00~20:59 사용자 제공 저녁 bedroom_evening 이미지 사용
- 홈 VN 시간이 낮에서 밤으로 건너뛰면 대사 전에 낮→저녁→밤 순서로 0.65초씩 크로스페이드

우선 확인 권장
1) DAY1 첫 도박 직후 한다/안 한다
2) DAY3 도박 잠금 안내 및 민재 메시지 중복
3) 돈 부족→서준/엄마/민재 차용→은행 잔액/거래내역
4) DAY10 서준 상환 메시지와 오버레이 배경
5) 17시대→21시 이상으로 시간이 건너뛰는 홈 장면의 배경 전환
6) 메시지 읽은 직후 홈 빨간 점
7) 대화 기록 긴 로그 스크롤
