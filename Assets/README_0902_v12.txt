도박예방게임 Scenario V3 누적 패치 v12

기준: v11 + 사용자가 확인한 후속 버그 수정

이번 수정 핵심
1. 메시지 앱 채팅 내역 유지
- 채팅방을 열 때 화면에 남은 말풍선 오브젝트가 아니라 ChatChannel.messageHistory를 원본으로 사용해 전체 말풍선을 재구성합니다.
- 앱 닫기/다음 날 진행 뒤 일부 말풍선만 사라져 내 답장 내역이 없어지는 현상을 방지합니다.
- 레거시 외부 메시지도 messageHistory에 기록합니다.

2. 밤샘 도박의 날짜/시간 진행
- 도박 중 밤을 지나 다음 오전 08:00 경계를 넘기면 현재 일차를 종료합니다.
- 다음 날 오전 10:00에 기상합니다.
- 일반 day_start 아침 독백과 겹치지 않도록 그 날의 일반 아침 시작 장면은 건너뜁니다.
- 도박 밤샘 전용: "언제 잠든 거지... 도박 화면을 보다가 그대로 잠들어 버렸다." → "벌써 오전 열 시다. ...학교에 늦었다."
- 이후 기존 지각 등교 흐름을 그대로 사용합니다.

3. 밤의 추가 차용은 다음 날 아침으로 이월
- 밤에 추가 차용을 선택하면 즉시 새벽 메시지를 보내지 않습니다.
- "이 시간에 돈 빌려 달라고 연락하기도 그렇다..." 이후 다음 날 10:00로 이동합니다.
- 이 경우 도박 밤샘 독백을 동시에 재생하지 않고 별도의 아침 문맥으로 처리합니다.
- 특수 기상 장면과 그 날의 부가 이벤트가 끝난 뒤 차용 대상 선택 → 해당 채팅방 메시지 선택지로 이어집니다.

4. 이미 한 번 빌린 상대 재차용 방지
- borrowed.mom / borrowed.seojun / borrowed.minjae 상태로 차용 선택지를 필터링합니다.
- 기존 차용 데이터와 신규 아침 차용 경로 모두 같은 상태를 사용합니다.

5. 지나간 대화 마스크 재구성
- 이전 런타임 복제 Viewport를 사용하지 않고 씬의 실제 History Viewport를 직접 사용합니다.
- 기존 RectMask2D 대신 UI Mask(stencil)를 강제 적용해 Viewport 밖 텍스트를 잘라냅니다.
- History Content 높이만 내용 길이에 따라 증가하고 텍스트 가로폭은 Viewport - 좌우 여백으로 고정합니다.
- 대화내역을 열면 가장 최신 대화가 보이도록 맨 아래로 자동 스크롤합니다.
- 메시지 말풍선은 지나간 대화 UI에 사용하지 않습니다.

6. v11의 도박 앱 클릭 SFX 및 v10까지의 누적 수정 유지
