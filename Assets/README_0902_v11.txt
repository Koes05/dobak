도박예방게임 Scenario V3 누적 패치 v11

적용 방법
1. Unity와 GitHub Desktop에서 프로젝트 파일을 수정 중이지 않은지 확인합니다.
2. Unity를 완전히 종료합니다.
3. 이 ZIP의 Assets 폴더를 프로젝트 최상위 Assets 폴더에 덮어씁니다.
4. Unity를 실행하고 컴파일이 끝난 뒤 Console 오류부터 확인합니다.

v11 핵심 변경
- v10까지의 누적 수정 유지.
- 밤새 도박을 계속해 오전 8시 경계를 넘기면 더 이상 같은 일차에서 시간이 순환하지 않습니다.
  이전 날 일정을 정리하고 다음 날 오전 10시로 기상하며, 늦은 도박/지각 관련 day_start 장면이 이어집니다.
- 밤에 잔액이 없어 돈을 더 빌리려는 경우 즉시 새벽 메시지를 보내지 않습니다.
  '오늘은 늦었으니 자고 아침에 생각하자' 장면 뒤 다음 날 오전 10시에 차용 흐름을 이어갑니다.
- 다음 날 차용 대상을 고르면 해당 인물의 메시지 채팅방이 우선 노출되고,
  채팅방 안에서 '돈을 빌려 달라고 메시지 보낸다' / '역시 보내지 않는다' 선택지가 뜹니다.
- 엄마/서준/민재에게 이미 한 번 빌렸다면 이후 같은 대상에게 다시 빌리는 선택지는 표시하지 않습니다.
- 모든 차용 대상을 이미 사용했다면 재차용 선택을 막고 별도 독백으로 종료합니다.
- 엄마/서준 차용 응답 시 실제 통장 잔액 +50,000원과 채무 +50,000원이 반영됩니다.
- 서준 후속 상환 장면은 debt_owner가 바뀌어도 borrowed.seojun 상태를 기준으로 추적합니다.
- 도박 앱 클릭 시 button_click SFX를 연결했습니다.
- 대화기록 UI는 기존 History Text를 숨기고, 기존 연한 사각형 영역의 위치/색을 기준으로
  새 Viewport + RectMask2D + Content + TMP Text 구조를 런타임에 만듭니다.
  대화기록에는 말풍선을 사용하지 않으며, 텍스트 가로폭은 Viewport 폭 - 좌우 여백으로 고정됩니다.
  내용이 길어지면 Content 높이만 증가하며, 열 때 가장 최근 기록이 보이도록 맨 아래로 자동 스크롤합니다.
- History Panel에 배경 Image가 없던 씬에서도 완전 불투명 배경을 생성해 기존 VN 텍스트가 비쳐 보이지 않게 합니다.
- 문제 선택지 UI/Answer_Text RectTransform/축약 문구는 v10 수정 유지.
- 민재 첫 메시지 알림 후 '(민재한테 메시지가 왔다. 확인해 보자.)' 유도도 v10 수정 유지.

권장 확인 순서
1. Console 컴파일 오류 여부
2. 문제 선택지 1336 화면
3. 대화기록 열기 -> 사각형 밖 텍스트가 보이지 않는지 / 최신 기록으로 내려가는지
4. 도박 앱 클릭 SFX
5. 일정 완료 후 밤에 도박을 반복하여 오전 8시를 넘겨보기 -> 다음 날 10시 기상/지각
6. 잔액 0 -> 차용 선택 -> 다음 날 10시 -> 대상 채팅방의 메시지 보내기 선택지
7. 서준 또는 엄마에게 한 번 빌린 뒤 다시 잔액 0 -> 이미 빌린 대상이 선택지에서 사라지는지
