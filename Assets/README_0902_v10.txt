도박예방게임 Scenario V3 핫픽스 v10

적용 방법
1. Unity를 완전히 종료합니다.
2. 이 압축파일의 Assets 폴더를 프로젝트 최상위에 덮어씁니다.
3. Unity를 실행하고 Console 컴파일 오류가 없는지 먼저 확인합니다.

v10 추가 수정
- 공부 선택지 Answer_Text의 폰트 크기는 런타임에서 더 이상 변경하지 않습니다.
- Answer_Text RectTransform을 Stretch로 고정하고 Left 150 / Right 150 / Top 0 / Bottom 0으로 맞췄습니다.
- 선택지 카드 X=440 유지, Y=-45부터 일정 간격으로 정렬했습니다.
- 선택지 카드 폭 1100, 높이 150으로 정리하고 Choice Number는 숨김 유지했습니다.
- 긴 선택지는 v9에서 축약한 StudyActivities.csv를 유지합니다.
- 대화 기록은 기존 씬 History Viewport를 사용하지 않고, 런타임에 별도의 Viewport -> Content -> TMP Text 구조를 새로 만듭니다.
- 대화 기록에는 말풍선을 사용하지 않습니다.
- 대화 기록 텍스트 가로폭은 Viewport 폭 - 좌우 32px씩으로 고정합니다.
- 로그가 길어질수록 Content 높이만 증가하며 Viewport 밖은 RectMask2D로 잘립니다.
- 대화 기록을 열면 최신 대화가 보이도록 자동으로 맨 아래로 스크롤합니다.
- DAY1 민재 첫 연락 알림이 오면 '(민재한테 메시지가 왔다. 확인해 보자.)' 유도 다이얼로그를 다시 표시합니다.
  실제 메시지 내용에 대한 독백은 채팅방을 직접 읽은 뒤에만 이어집니다.

v9까지의 누적 변경사항도 포함되어 있습니다.
