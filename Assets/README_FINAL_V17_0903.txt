이번 ZIP은 자동 설치용 Editor 패처가 아닙니다.
- 기존 BankUI.cs와 ScenarioV3Flow.csv를 직접 덮어씁니다.
- ScenarioV3FinalRuntimeFix.cs는 TabletUI에서 자동 부팅되는 정상 런타임 구성 요소입니다.
- 설치 스크립트가 아니라, 실행 중 기존 ScenarioV3 데이터/상태 연결을 직접 보정합니다.
- 과거 V13 자동 설치 파일 이름은 무해한 빈 파일로 덮어써 재실행을 막습니다.

주요 확인 경로
- 늦은 등교 안내를 닫은 뒤에만 학교 이동
- 대화 기록 Viewport 안에서 세로 스와이프
- 거래 내역 최신 거래가 최상단, 세로 스와이프
- 야간 차용 선택 후 취침 앱으로만 다음 날 이동
- 다음 날 태블릿 홈 위에서 바로 차용 대상 선택
- 서준/민재 상환 선택은 채팅 버튼이 아니라 채팅 화면 위 다이얼로그
- 선택 후 실제 답장만 메시지 말풍선으로 기록
- 돈이 없을 때 상환 선택은 상환 연기 답장으로 연결
- 분기점 되감기 시 체크포인트 이전 채팅/VN 기록 유지
- 처음부터 다시 시작할 때만 전체 기록 초기화
- 민재 회복 엔딩은 사과/관계 회복 없이 냉소적 상환 요구
- 전액 손실 이후 +20,000원 1회, -40,000원 1회, 이후 기존 반복 손실
