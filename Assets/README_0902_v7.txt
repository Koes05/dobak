적용
- Unity를 완전히 종료한 뒤 ZIP 안의 Assets 폴더를 프로젝트 최상위에 덮어쓰기.
- 기존 v6을 먼저 적용할 필요 없이 v7만 덮어써도 됨.

v7 긴급 수정
1) DialogueManager.cs 컴파일 오류 수정
   - StringComparison 사용에 필요한 using System; 추가
   - CS0103 2건 해결

2) 저녁 방 에셋 교체
   - v6에서 bedroom_evening.png에 잘못 들어간 메시지 앱 스크린샷 제거
   - 실제 방 구도의 저녁/노을 이미지로 교체
   - 18:00~20:59 저녁, 21:00~05:59 밤, 그 외 낮

3) 낮→저녁→밤 시간 변화 연출 보강
   - 집 VN에서 시간이 낮에서 밤으로 크게 이동하면 바로 밤으로 자르지 않음
   - 낮→저녁→밤 순으로 짧은 크로스페이드 후 대사 표시
   - 취침 arc도 위 전환 로직을 타도록 수정

4) 서준 상환 메시지 독백
   - d10_seojun_followup_02는 overlay로 유지
   - 메시지 앱 화면 위에서 '(답장은 금방 쓸 수 있었다...)' 독백이 나오고 도박 장면으로 전환하지 않음

5) 메시지 읽음/빨간 점 동기화
   - 채팅방을 실제로 열어 읽는 순간 unread_count와 앱 빨간 점 즉시 재계산
   - 같은 프레임 UI 정리 지연에 대비해 다음 프레임 한 번 더 동기화
   - 다른 연락처에 실제 unread가 남아 있으면 빨간 점은 정상 유지
