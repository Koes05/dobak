# Scenario V3 마감 수정 체크리스트

## 1. 시나리오와 대사 우선 작업

- [x] 모든 대사를 실제 말하듯 다시 다듬는다.
- [x] 주인공의 망설임에는 `...`, 짧은 문장, 문장 사이 공백을 사용해 호흡을 만든다.
- [x] 민재는 짧고 재촉하는 채팅 말투, 서연은 구체적인 과제 대화, 점장은 관찰 후 조심스럽게 묻는 말투로 구분한다.
- [x] 상담 교사와 도박예방 전담관의 설명조 말투를 자연스러운 대화로 고친다.
- [x] 엄마를 엔딩에서 처음 등장시키지 않고 초반 안부 연락부터 중반의 걱정과 돈 문제 반응까지 꾸준히 등장시킨다.
- [x] 민재의 새 메시지 앞뒤에 주인공의 갈등 독백을 추가한다.
- [x] 갑자기 장면이 바뀌지 않도록 주인공의 반응과 다음 행동을 연결하는 대사를 추가한다.
- [x] 9일차 이후 학교, 서연, 민재, 점장, 가족 관련 장면을 보강한다.
- [x] 엔딩 직전에 선택 결과를 회수하는 여러 개의 비주얼 노벨 장면을 배치한다.
- [x] 회복 엔딩은 교사 상담, 부모님과의 대화, 서연과의 관계, 빚 상환 계획을 차례로 보여 준다.
- [x] 예방 엔딩은 도박을 적게 했다는 결과만 설명하지 않고 일상 선택이 만든 변화를 대화로 보여 준다.
- [x] 도움을 요청하지 못한 엔딩은 민재의 재접촉, 빚 독촉, 무너진 관계와 주인공의 재은폐를 장면으로 보여 준다.
- [x] 엔딩 카드는 장면의 내용을 반복하지 않고 마지막 여운과 상담 번호만 간결하게 표시한다.
- [x] 서준에게 돈을 빌리면 부탁 메시지, 송금 답장, 이후 독촉 메시지가 나오게 한다.
- [x] 알바에 결근하면 점장의 전화나 메시지와 주인공의 반응이 나오게 한다.
- [x] 조별과제 문제를 풀면 주인공이 서연에게 결과를 직접 메시지로 보내게 한다.
- [x] 조별과제 미진행 여부에 따라 서연의 반응과 이후 관계 대사를 다르게 출력한다.
- [x] 카페에 이동하기 전에는 카페 배경과 점장 대사가 절대 나오지 않게 한다.

## 2. 장면 진행 방식

- [x] 문제 정답 및 오답 선택 직후 화면이 넘어가지 않도록 반응 장면을 둔다.
- [x] 오답 문구 `아, 이 번호는 아닌 것 같은데...`는 문제 화면 안내가 아니라 주인공 다이얼로그로 출력한다.
- [x] 모든 주요 장면은 `계속` 버튼 또는 화면 터치 후 다음 장면으로 넘어가게 한다.
- [x] 메시지 선택 후에는 주인공이 보낸 말풍선을 읽을 수 있는 시간을 둔 뒤 다음 연출로 넘어간다.
- [x] 지나간 대화 기록의 가로 폭과 줄바꿈을 수정해 문장이 세로 한 글자씩 나오지 않게 한다.

## 3. 취침과 시간 사용

- [x] 취침 앱에서 예상 수면 시간과 수면 시간 계산 문구를 모두 제거한다.
- [x] 취침 안내 문구를 `주무시겠습니까?`로 바꾼다.
- [x] 취침 화면 좌측 상단의 `취침` 제목을 제거한다.
- [x] 취침 화면을 상단 상태 표시줄과 하단 내비게이션 바 사이 높이에 맞춘다.
- [x] 지도 앱과 취침 앱의 홈 화면 위치를 서로 바꾼다.
- [x] 오후 4시나 6시에는 취침할 수 없게 하고 자연스러운 저녁 활동으로 시간을 보낼 수 있게 한다.
- [x] 늦은 시간 도박 선택 여부로 다음 날 피로와 수면 부족 반응을 계산한다.
- [x] 적절한 시간이 되면 취침 앱에 유도 표시를 띄운다.

## 4. 앱 유도와 홈 화면

- [x] 공부 앱에서 조별과제를 진행할 수 있다는 튜토리얼 독백을 추가한다.
- [x] 새 메시지, 진행 가능한 공부, 취침 가능 시 해당 앱 우측 상단에 빨간 원형 점을 표시한다.
- [x] 유도 대상 앱을 열거나 행동을 완료하면 빨간 점을 제거한다.

## 5. 공부와 문제 화면

- [x] 문제 선택지를 가로로 충분히 넓히고 세로 간격을 일정하게 맞춘다.
- [x] `자료 조사 1 / 1` 진행 표시를 문제 카드 안쪽 좌측 상단으로 옮긴다.
- [x] 긴 선택지는 두 줄 이상으로 표시하고 글자가 잘리지 않게 높이를 자동 조절한다.
- [x] 모든 문제의 선택지 길이를 점검해 동일 문제가 반복되지 않게 한다.
- [x] 앱 전체 화면 문제 카드가 상단 및 하단 UI와 겹치지 않게 한다.

## 6. 이동과 지도

- [x] 학교나 카페에서 집으로 돌아올 때도 검은 화면의 이동 중 연출을 재생한다.
- [x] 학교 수업을 마치고 귀가한 날에는 지도 앱의 학교 버튼을 잠근다.
- [x] 평일 학교, 휴일 카페 조건과 이미 완료한 일정 조건을 함께 검사한다.
- [x] 아침 시작 독백은 집에서 출력하고 실제 이동 완료 후 목적지 장면을 출력한다.

## 7. 은행 앱

- [x] 거래 시각을 실제 컴퓨터 시간이 아닌 게임 내 일차와 시각으로 기록한다.
- [x] 최신 거래가 항상 거래내역 최상단에 오게 한다.
- [x] 거래내역을 손가락 드래그와 마우스 휠로 스크롤할 수 있게 한다.
- [x] 거래처 이름을 현재보다 왼쪽으로 옮긴다.
- [x] 금액과 거래 후 잔액을 현재보다 약간 오른쪽으로 옮긴다.
- [x] 입금은 초록색, 출금은 진한 남색으로 유지한다.
- [x] 거래 행 테두리를 회색에서 연한 남색으로 바꾼다.

## 8. 공통 가독성

- [x] 민재·서연·점장 등 캐릭터 일러스트는 화면 좌측에 통일해서 배치한다.
- [x] 캐릭터 일러스트가 대화 상자와 이름표를 가리지 않도록 크기와 기준점을 맞춘다.
- [x] 게임 내 주요 UI 글꼴을 굵게 조정한다.
- [x] 글자를 줄여 억지로 넣지 않고 긴 문장은 다음 페이지나 다음 줄로 보낸다.
- [x] 선택지는 가로 폭과 세로 높이를 늘려 버튼 밖으로 글자가 잘리지 않게 한다.
