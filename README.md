# 공짜 5천원 - AI 작업 인수인계

청소년 도박 예방을 목적으로 만든 Unity 기반 태블릿 시뮬레이션 게임이다. 플레이어는 제한된 하루의 시간을 학교, 숙제, 알바, 수면, 도박 등에 사용하며 본인의 선택으로 서로 다른 결과를 경험한다.

이 문서는 다른 AI 또는 개발자가 기존 구현을 버리지 않고 이어서 작업할 수 있도록 작성한 인수인계 문서다.

## 가장 먼저 확인할 것

- Unity 버전: `6000.4.0f1`
- 기준 저장소: `dobak`
- 현재 구현 브랜치: `codex/backup-main-20260831`
- 현재 구현 커밋: `5111c7e feat: add turn-based daily game flow`
- 메인 플레이 씬: `Assets/Tablet/TabletUI.unity`
- 화면 방향: 가로형 태블릿 UI
- 원본 `main` 브랜치는 보존되어 있다.

새 프로젝트나 새 메인 씬을 만들지 말고 기존 `TabletUI` 씬과 기존 앱 구조를 수정·확장해야 한다. 프로젝트에는 이미 메시지, 공부, 지도, 은행, 도박 등의 UI와 리소스가 들어 있다.

## 게임 방향

핵심은 도박을 강제로 따라가는 선형 스토리가 아니라, 시간과 행동을 플레이어가 직접 선택하고 그 결과를 체감하는 시뮬레이션이다.

기본 흐름:

1. 친구 민재에게 무료 포인트 사이트 초대 메시지가 온다.
2. 플레이어가 거절하면 위험을 차단한 결말로 진행된다.
3. 수락하면 도박 기능이 열리지만, 이후에도 일상 또는 도박 중 무엇을 할지 직접 선택한다.
4. 모든 행동은 시간을 소비한다.
5. 평일에는 학교와 숙제, 주말에는 알바가 필수 일정이다.
6. 수면은 매일 필요하다.
7. 일정 누락, 반복 도박, 빚, 환전 시도, 도움 요청 등에 따라 결과가 달라진다.

주인공의 성격이나 대사를 과도하게 정하지 않는다. 선택지는 `예`, `아니오`, `접속한다`, `닫는다`처럼 중립적으로 표현하고, 결과 설명은 짧은 독백 또는 나레이션 중심으로 구성한다.

## 현재 구현된 기능

### 날짜와 시간

- 총 14일 진행
- 하루 시작 시간은 오전 7시
- 오전/오후 형식으로 시간 표시
- 지도 이동, 학교, 알바, 숙제, 도박 한 판 등에 시간이 소모됨
- 시간이 자정을 넘으면 다음 날로 전환됨

### 체크리스트

평일:

- 학교 가기: 지도 앱에서 학교 선택
- 숙제하기: 공부 앱에서 오늘의 5문제 완료
- 잠자기

주말:

- 알바 가기: 지도 앱에서 카페 선택
- 잠자기

필수 일정을 놓친 날이 누적되며, 일정이 반복해서 무너지면 `일상 붕괴` 결말이 발생한다.

### 공부 앱

- 기존 씬에 등록된 문제를 사용함
- 평일에는 학교 수업을 마치기 전까지 공부 앱이 열리지 않음
- 평일마다 5문제를 무작위로 선정함
- 날짜를 시드로 사용하므로 같은 날 앱을 다시 열면 문제 순서가 유지됨
- 하루가 바뀌면 새로운 문제가 선정됨
- 5문제를 모두 풀면 숙제가 완료되고 2시간이 소모됨
- 주말에는 새로운 숙제가 없다는 상태를 표시함

### 지도와 알바

- 게임과 지도 앱의 초기 위치는 모두 집으로 통일됨
- 기존 집·학교·카페 이미지와 현재 위치 핀 리소스를 사용함
- 각 장소에 예상 이동시간을 표시함
- 평일 학교는 이동시간을 포함해 오전 10시까지 도착해야 함
- 학교 이동: 이동 1시간 + 수업 7시간
- 주말 카페 이동: 이동 1시간 + 근무 6시간
- 알바 완료 시 은행 잔액에 가상 급여가 입금됨
- 장소 이동 시 화면이 어두워졌다가 다시 나타나는 전환 연출이 있음

### 잠자기

- 홈 체크리스트 아래의 `잠자기` 버튼으로 실행
- 화면 암전 후 다음 날 오전 7시로 전환
- 다음 날 현재 위치는 집으로 돌아옴
- 부족한 수면 시간은 내부적으로 누적됨

### 메시지와 선택

- 홈 상단 알림 미리보기는 한 줄을 넘으면 `...`으로 표시함
- 게임 시작 직후 메시지가 미리 쌓이는 방식이 아니라 첫 알림부터 순차적으로 발생함
- 친구 초대, 학교 및 숙제 알림, 알바 알림, 은행 알림, 도박 사이트 유도 알림 등이 사건에 맞춰 발생함
- 같은 이벤트 메시지가 행동마다 반복되지 않도록 고유 키로 중복 전송을 차단함
- 초대를 수락하기 전에는 도박을 실행할 수 없음
- 도박 앱은 로그인·회원가입 없이 허구 사이트 홈으로 바로 열림
- 로컬 계정 파일을 생성하거나 읽고 쓰지 않음

### 돈과 결말

- 은행 잔액, 사이트 포인트, 빚, 일정 누락을 홈에서 확인 가능
- 잔액 조건에 따라 가상의 돈 빌리기 기능이 나타남
- 충분한 사이트 포인트가 생기면 환전 시도 기능이 나타남
- 도움 요청은 조건이 충족된 뒤 선택 가능
- 실제 도움 요청 분기는 도박을 시작한 뒤 빚이 생겼을 때 체크리스트에 나타남
- 구현된 결말: 위험 차단, 일상 붕괴, 빚, 먹튀, 도움 요청, 일상 회복

모든 도박, 대출, 입금, 환전은 게임 내부의 허구 데이터이며 실제 결제, 네트워크, 대출 또는 환전 기능을 연결하면 안 된다.

## 핵심 코드

- `Assets/Tablet/Script/GameFlowManager.cs`
  - 전체 날짜, 시간, 일정, 체크리스트, 메시지 이벤트, 전환 연출, 결말을 관리한다.
  - `TabletUI` 씬에서 런타임에 자동 생성된다.
- `Assets/Tablet/Script/QuizManager.cs`
  - 평일별 무작위 5문제와 숙제 완료 이벤트를 관리한다.
- `Assets/Tablet/Script/DialogueManager.cs`
  - 민재의 초대 대화와 게임 흐름 선택을 연결한다.
- `Assets/Tablet/Script/AppWindow.cs`
  - 앱 열기와 닫기 상태를 외부에 알린다.
- `Assets/Junsang/Scripts/Map/MapLocationController.cs`
  - 기존 지도 위치 값을 학교, 카페, 집으로 연결한다.
- `Assets/Junsang/Scripts/Bank/CoinManager.cs`
  - 은행 및 사이트 포인트와 알바비 등 외부 수입 기록을 관리한다.
- `Assets/Junsang/Scripts/SlotMachine/SlotMachineManager.cs`
  - 도박 한 판의 시간 소비와 결과 이벤트를 전달한다.

## 자동 QA

- `Assets/Editor/ProjectQa.cs`
  - 메인 씬, 핵심 매니저, 공부 문제 수, 필수 이미지 리소스를 검사한다.
- `Assets/Editor/PlayModeCapture.cs`
  - 알림 말줄임, 등교 전 공부 잠금, 지도 리소스, 학교 이동, 공부 앱, 로그인 없는 도박 앱, 잠자기, 다음 날 화면을 자동 캡처한다.
- QA 결과 이미지는 프로젝트의 `Logs` 폴더에 생성된다.

마지막 검증에서 스크립트 컴파일과 플레이 흐름은 통과했다. Unity 에디터의 Search 인덱서에서 발생하는 `ArgumentOutOfRangeException`이 로그에 한 번 나타날 수 있으나 게임 코드 예외는 아니었다. 게임 코드의 `NullReferenceException`, `MissingReferenceException`, C# 컴파일 오류는 확인되지 않았다.

## 작업 시 지켜야 할 규칙

- 기존 씬과 이미 구현된 앱을 우선 사용한다.
- 사용자 요청 없이 새 메인 씬이나 별도 프로젝트를 만들지 않는다.
- 플레이어에게 도박을 강제하지 않는다.
- 도박 방법, 전략, 실제 사이트, 실제 결제 경로를 제공하지 않는다.
- 실제 네트워크, 결제, 대출, 현금화 기능을 구현하지 않는다.
- 이름과 학교명 등 사용자 입력 개인정보를 저장하지 않는다.
- 저장/불러오기는 별도 요청 전까지 추가하지 않는다.
- 메시지는 사건이 발생한 시점에 보내고 시작부터 대량으로 쌓아두지 않는다.
- 같은 메시지가 매 행동마다 반복되지 않도록 이벤트 조건과 중복 방지를 유지한다.
- UI는 일반 게임 HUD보다 태블릿 운영체제와 앱 화면처럼 보여야 한다.
- 기능을 수정한 뒤에는 `TabletUI` 씬에서 실제 플레이 모드로 확인한다.
