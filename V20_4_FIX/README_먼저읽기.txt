DOBak V20.4 통합 수정 패치

V20.3 최종 검증에서 빠져 있던 두 문장(d1_evening_01, d8_lecture_03)의 링크→앱 표현을 보완한 버전입니다.
V20.1과 V20.3은 다시 실행하지 마세요.

적용 방법
1. Unity, Excel, ScenarioV3.csv를 열어 둔 편집기를 모두 종료합니다.
2. 이 ZIP의 모든 내용물을 Assets와 ProjectSettings가 보이는 Unity 프로젝트 최상위 폴더에 풉니다.
3. 프로젝트 최상위 폴더의 PowerShell에서 아래 명령을 실행합니다.

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\V20_4_FIX\Apply_Dobak_V20_4.ps1"

4. DOBak_V20_4_PATCH_STATUS.txt 첫 줄이 아래와 같은지 확인합니다.

DOBak V20.4 INTEGRATED PATCH: PASS

5. Unity를 다시 열고 컴파일이 끝난 뒤 Intro에서 새 게임으로 QA합니다.

이번 버전에는 BAT 파일이 없습니다.

안전장치
- 실행 전에 Unity 실행 여부와 대상 파일 잠금을 먼저 검사합니다.
- 원본은 _Dobak_V20_4_Backup_날짜_시간 폴더에 저장합니다.
- 오류가 나면 실패 단계와 실제 원인을 화면과 상태 파일에 표시하고 원본을 복원합니다.
- C# 표시 호환 패치는 선택 항목입니다. 로컬 소스가 달라 적용하지 못해도 새 런타임 보정이 화면을 처리하며, 상태 파일에 경고만 남깁니다.

통합 반영
- 전체 대화 문체 정리
- 플레이어 화면의 P/포인트 표현을 원 단위로 표시하고 내부 환산·자동 환전은 유지
- 최초 유입만 링크, 이후 앱 표현
- 스케줄러에 이미 메모된 것으로 문장 수정
- 학교 종료 후 집으로 돌아가 남은 일정 확인
- 메시지·차용·상환·학교·공부·알바 때문에 도박 앱이 제한될 때 이유 안내
- 실제 도박 밤샘만 오전 10시 강제 기상
- 평일 밤샘은 학교 유도, 주말 밤샘은 카페 결근 안내
- 지도 화면 위 지각 안내 후 플레이어가 학교를 직접 선택
- VN 지난 대화 RectMask2D·세로 스크롤·일차별 초기화
- 채팅과 은행 기록 유지, 분기 되감기 시 미래 기록만 제거
- 민재 첫 차용의 ‘이번엔’ 제거, 실제 차용 전까지 재제안 가능
- 서준·민재 상환 선택을 채팅 위 다이얼로그로 표시
- 도박 7회차 +20,000원, 8회차 -40,000원
- 3·6·10일차 노트북 수리비 압박 문맥
- 은행 최신 거래 최상단·세로 스크롤·마스크
